Selected Research Projects

ECG-LabWAS

Laboratory-Wide Association Study Using a Single-Lead ECG Foundation Model

ECG-LabWAS investigates whether single-lead ECG signals contain information associated with common clinical laboratory abnormalities.

The project uses a fine-tuned ECG foundation model for multi-task laboratory abnormality classification, together with independent external validation.

  • Applied a pretrained ECG foundation model to laboratory-wide abnormality screening.
  • Investigated 50 laboratory tests covering 89 abnormality directions.
  • Developed models using the MC-MED clinical cohort.
  • Evaluated generalization using the independent MIMIC-IV cohort.
  • Identified 33 abnormality directions meeting the study-defined screening criteria in both cohorts.
  • Analyzed associations among laboratory abnormalities, model predictions, and clinical outcomes.

Research Areas: ECG Foundation Models, Medical AI, Multi-task Learning, External Validation.
